# Derive a piece from another

Use once the source draft exists and I have done the voice pass on it. This piece has its
own folder; the source lives in another one.

## Steps

1. Read `brief.md`. Its "Made from" section names the source draft: read that, and the
   Voice section.
2. Write this piece's main draft, named in the brief, in the shape its type needs:
   - linkedin post — the hook in the first two lines, short paragraphs, no markdown
     headings (LinkedIn strips them), 3-5 hashtags at the end, within the character
     limit in the brief.
   - x post — a thread; each post under 280 characters, numbered.
   - quote — 5 to 8 lines from the source that stand on their own.
   - anything else — ask me what shape it should take before writing.
3. Keep my phrasing wherever it already works. This is repackaging, not rewriting.
4. Leave `[MY STORY: ...]` markers in place; never fill them in.
5. Tell me which claims in the new piece still need a source.
